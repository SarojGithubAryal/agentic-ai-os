# Agentic AI OS – Admin Dashboard

The official administration dashboard for the Agentic AI OS platform.  
It provides a graphical interface for managing AI providers, memory, tools, workflows, agents, applications, and more.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 6
- **Styling**: Tailwind CSS v4, shadcn/ui components
- **State Management**: TanStack Query (server state), React Context (auth)
- **Routing**: React Router v7
- **HTTP Client**: Axios
- **Forms**: React Hook Form + Zod
- **Notifications**: Sonner
- **Icons**: Lucide React

## Prerequisites

- Node.js 20+
- Backend server running at `http://localhost:3000` (the `agentic-ai-os` backend)

## Getting Started

```bash
npm install
npm run dev
